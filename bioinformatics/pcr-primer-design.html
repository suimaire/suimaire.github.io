PCR과 프라이머 디자인

어디부터 어디까지 복제할 것인가

두 DNA를 구별할 수 있는 프라이머를 설계하고, 계산이 말해 주는 것과 아직 알 수 없는 것을 실험 노트에 기록하세요.

기록 도구를 준비하고 있습니다. 이 안내가 계속 보이면 자동 저장과 계산을 사용할 수 없습니다. 기본 문항을 읽고 종이에 기록하거나 브라우저 인쇄를 사용하세요.

이 기기의 브라우저에만 기록합니다. 이름과 학번은 필요하지 않습니다. 중요한 기록은 JSON으로 내보내세요. 자유 서술은 자동 채점하지 않습니다.

00 / 5분

두 시료를 어떻게 구별할 것인가?

인공 DNA A는 420 bp입니다. B는 A의 121~200번 구간 80 bp가 결실된 340 bp DNA입니다. 배경 DNA C가 함께 존재할 수도 있습니다. 모두 수업을 위해 만든 인공 서열이며 자연 유전자나 실험 검증 자료가 아닙니다.

이 두 칸은 처음 예측입니다. 이후 달라진 설명은 활동 07에 별도로 기록하세요.

예측 후 해설 열기

검출하려는 차이와 프라이머 결합 구간을 함께 고려해야 합니다. 밴드가 없을 때는 DNA의 부재 외에도 결합 부위 변화, 반응 억제, 시약이나 과정의 문제를 검토해야 합니다.

01 / 10분

PCR에서 매 단계 달라지는 것

온도는 한 프로토콜의 예시입니다. 실제 조건은 효소, 프라이머와 시료에 따라 달라집니다. Taq는 신장 온도에서만 작동하기 시작하는 스위치가 아닙니다.

1. 변성 / 예시 95 °C

가열로 상보적인 두 가닥이 분리됩니다. DNA의 당-인산 골격을 잘라내는 단계가 아닙니다.

반응에 필요한 것
구성 요소역할
DNA 주형상보적인 새 가닥의 염기 순서를 결정합니다.
두 프라이머상보적으로 결합하고 합성을 시작할 3′ 끝을 제공합니다.

초기 주기의 산물 해설 열기

일반적인 긴 이중가닥 주형에서 1주기의 새 가닥은 한쪽 끝만 프라이머로 정해지고 반대쪽은 더 길게 이어집니다. 그 가닥이 주형이 되면 2주기부터 양 끝이 정해진 정확한 길이의 단일가닥이 생깁니다. 그 길이의 이중가닥 산물은 3주기부터 생깁니다. 위 신장 그림도 첫 주기의 긴 합성을 보여 줍니다. 2ⁿ은 모든 분자가 매 주기 복제된다는 이상적인 배증 모형이며 실제 수율 예측식이 아닙니다.

02 / 10분

두 프라이머의 방향

상단 5′-AGTCCGTA-3′

아래 8 nt 예시는 방향 학습용이며 실제 PCR용 프라이머가 아닙니다.

방향 해설 열기

상보 서열은 3′-TCAGGCAT-5′, 역상보 서열은 5′-TACGGACT-3′입니다. 오른쪽 상단 주형의 역상보 서열을 주문해야 상단에 결합해 왼쪽으로 신장하는 기본 배치를 만들 수 있습니다. F/R은 이름이며 실제 결합 방향은 서열이 결정합니다.

03 / 20분

직접 프라이머를 배치하기

화면 좌표는 1부터 세며 양 끝을 포함합니다. A의 결실 구간은 121~200입니다. 서열은 모두 상단 5′→3′ 기준입니다.

선택할 결합 구간

확대 보기에서 시작과 끝을 차례로 누르거나 마우스로 드래그하세요. 키보드는 화살표로 이동하고 Enter로 두 끝을 선택합니다. 드래그 방향은 신장 방향을 뜻하지 않습니다.

A 염기별 확대 보기

각 칸의 위는 상단, 아래는 상보 하단입니다. 줄을 바꾸어도 같은 가닥이 이어집니다. 읽는 방향: 상단 5′→3′, 하단 3′→5′.

A, B, C 전체 인공 서열 보기
서열 자료를 불러오는 중입니다. 계산 도구 없이 진행할 때는 활동 00의 결실 모형을 사용하세요.

A/C/G/T만 지원합니다. 공백과 대소문자를 정리하며 각 프라이머는 최대 100 nt입니다. FASTA 헤더, N, 5′ 꼬리, 부분 결합, 불일치, 원형 DNA는 지원하지 않습니다.

직접 배치한 뒤 계산을 누르면 결합 위치와 예상 산물이 표시됩니다.

제공된 짧은 선형 DNA에서 완전 일치 결합만 검사합니다. 모든 F/R, F/F, R/R 조합을 탐색합니다. 미검출은 실제 증폭 불가능을 뜻하지 않으며, 여기서 유일한 산물도 실제 유전체 특이성을 뜻하지 않습니다.

배치 해설 열기

두 형태에서 모두 결합할 수 있는 결실 양옆에 프라이머를 배치하면 결실 차이가 산물 길이에 반영될 수 있습니다. 길이는 양쪽 프라이머 결합 구간을 포함합니다. 겹치는 결합 구간은 이 모형의 지원 범위 밖입니다.

04 / 10분

숫자가 적절하면 좋은 프라이머인가?

약 18~25 nt와 GC 약 40~60%는 일반적인 출발점입니다. 합격선이 아닙니다. 두 프라이머의 Tm, 3′ 말단, 자기 상보성, 서로의 상보성, 비표적 결합은 서로 다른 검토 항목입니다.

Tm: 정밀 계산 전

간이 Tm 보기

2×(A+T)+4×(G+C)는 염기 조성 기반 근사값입니다. 반응의 염, Mg2+, 올리고 농도와 최근접 염기 효과를 반영하지 않습니다. 적정 결합 온도, 성공률이나 합격 여부를 판정할 수 없습니다.

현재 F와 R 서열을 입력하세요.
상보 구간 관찰을 위한 고정 예시

아래는 입력한 프라이머의 분석 결과가 아닌 고정 교육 예시입니다. 상보 구간 관찰, 열역학적 안정성 미평가.

Hairpin / 한 분자 안의 상보 구간

5′-GCGCAAAAGCGC-3′

5′ G C G C ┐
   | | | |  A A
3′ C G C G ┘A A

양쪽 GCGC 구간이 역평행으로 짝지을 수 있고 가운데 AAAA는 고리 구간입니다.

Primer dimer / 두 분자 사이의 상보 구간

5′ A A A A G C G C 3′
           | | | |
        3′ C G C G T T T T 5′

교육 예시 주문 서열은 5′-AAAAGCGC-3′와 5′-TTTTGCGC-3′입니다. 두 3′ 쪽 상보 구간을 관찰할 수 있습니다. 안정한 구조나 형성 확률을 확정하지 않으며 ΔG를 계산하지 않습니다.

세 후보 해설 열기

P2는 표적 A와 B의 길이 차이를 보여 주지만 배경 C에서도 추가 산물이 예상됩니다. P3의 F는 결실 내부에 결합합니다. 결실 여부를 선택적으로 구별하려는 다른 목적에는 검토할 수 있으나 두 형태를 모두 증폭하려는 목적에는 맞지 않습니다. P1도 이 세 인공 서열 밖의 특이성이나 실제 반응 성공을 검증한 프라이머가 아닙니다.

05 / 10분

예상 산물과 실험 증거 구별하기

완전 일치 모형의 예상 산물입니다. 실제 실험 결과가 아닙니다.

활동 03에서 현재 설계의 산물을 계산하면 A, B, C, A+C, B+C의 개념도가 표시됩니다.

짧은 선형 DNA가 더 멀리 이동하도록 log10(bp)로 위치만 표시합니다. 밴드 밝기는 수율이나 발현량을 뜻하지 않습니다. 같은 길이의 산물은 한 위치에 겹칠 수 있으며 출처가 있는 산물 목록은 따로 보존합니다.

실험 증거 해설 열기

NTC는 주형을 넣지 않은 대조군입니다. NTC 신호에는 오염, 프라이머 유래 산물 등 여러 가능성이 있습니다. 양성 대조군도 실패했다면 시료 음성을 DNA 부재로 해석하기 어렵습니다. 양성 대조군과 NTC 외에 시료별 추출 상태와 반응 억제를 살피는 내부 대조도 검토하세요. 예상 크기의 밴드 하나는 정체의 확정이 아닙니다. 산물 서열 확인 등 추가 증거가 필요합니다.

06 / 10분

NCBI Primer-BLAST로 옮겨가기

앞의 계산은 세 인공 서열 안에서만 수행했습니다. 실제 서열은 교사가 지정한 표적 또는 직접 선택한 RefSeq를 NCBI에서 조회하세요. 인공 서열을 자연 유전자나 유전체 특이성 검증 자료로 옮겨 적지 마세요.

새 후보 설계는 확인한 RefSeq를 주형으로 설정합니다. 기존 프라이머 재검토는 출처가 있는 두 주문 서열을 입력하고 검색 범위를 확인합니다.

아래 값의 출처는 학생이 외부 결과에서 기록한 값입니다. 이 학습지가 NCBI 검색을 실행하거나 검증하지 않습니다. 결론은 검색 데이터베이스와 설정 범위에 제한됩니다. mRNA 데이터베이스만 검색한 결과를 genomic DNA 특이성 확인으로 확대하지 마세요.

외부 도구 사용 해설 열기

RefSeq의 버전, 생물종, 전사체 범위와 검색 데이터베이스를 함께 남겨야 같은 조건에서 결과를 다시 검토할 수 있습니다. 후보 순서는 실험 성공의 순위가 아닙니다. 접속하지 않아도 미실시와 검토 계획을 적으면 기본 활동을 마칠 수 있습니다.

최종 설계 기록

처음의 설명, 설계 변화, 계산과 실험 증거를 비교하여 최종 실험 노트를 완성하세요.

최종 검토 안내 열기

계산의 범위, 외부 검색의 범위와 실제 실험 증거를 구별했는지 읽어 보세요. 점수를 매기는 화면이 아니라 다른 사람이 판단 과정을 이해할 수 있는 기록을 만드는 활동입니다.

선택 확장 / RNA 발현을 보려면? / 약 15분

RNA에서 역전사로 만든 cDNA와 gDNA는 주형의 구성이 다릅니다. 아래는 길이와 좌표를 생략한 개념도입니다.

Exon-exon junction에 걸친 프라이머는 gDNA와의 구별에 도움을 줄 수 있습니다. Intron을 사이에 둔 프라이머 쌍은 gDNA와 cDNA에서 다른 길이의 산물을 만들 수 있습니다. 어느 방식도 gDNA 증폭 가능성을 절대 0으로 보장하지 않습니다. 유사 유전자와 가공 위유전자도 검토 대상입니다.

RT(-) 대조군은 역전사 효소를 넣지 않은 대조입니다. 남아 있는 DNA의 영향을 살피는 데 사용합니다. qPCR에는 짧은 산물을 주로 쓰지만 실제 정량에는 증폭 효율 검증이 필요합니다. 융해 곡선의 단일 피크도 표적 산물의 정체를 보장하지 않습니다.

확장 해설 열기

검출하려는 전사체, exon 구조와 gDNA 잔존 가능성을 함께 검토하세요. 실제 정량 데이터가 없으므로 이 학습지는 Cq, 발현량이나 증폭 효율을 만들어 내지 않습니다.
