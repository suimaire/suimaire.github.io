01 / 10분

한 주기의 반응을 따라가 보기

반응 혼합

상보적인 두 DNA 가닥과 프라이머, 효소, 합성 재료를 함께 준비합니다.

PCR mixture

  • Template DNA 주형
  • Forward primer 합성 시작점
  • Reverse primer 합성 시작점
  • DNA polymerase 가닥 연장
  • dNTP 합성 재료
  • Mg2+를 포함한 buffer 반응 환경

현재 단계의 주요 요소는 굵은 글자와 밑줄로 표시합니다.

회색 선: 기존 DNA / 청록 선: primer / 검정 선: 새 DNA / Pol: 중합효소. 95°C, 60°C, 72°C는 한 예시 protocol입니다. 실제 조건은 프라이머와 반응 조건에 따라 달라지며 Taq가 72°C에서만 작동하는 것은 아닙니다.

다음 주기의 주형이 되면?

1주기: 새 가닥은 한쪽 끝만 프라이머로 정해진 긴 산물입니다.

긴 이중가닥 주형에서 시작한 교육용 모형입니다. 대표적인 가닥만 보여 주며 실제 반응의 모든 분자와 비율을 나타내지 않습니다. 실제 PCR 효율은 항상 100%가 아닙니다.

증폭할 영역의 양 끝을 직접 정하는 것은 무엇인가?

정확한 길이의 산물은 언제 생길까?

1주기의 새 가닥은 반대쪽 프라이머 위치에서 자동으로 끝나지 않습니다. 이 긴 가닥이 다음 주기의 주형이 되면 2주기부터 두 프라이머 위치로 양 끝이 정해진 단일가닥이 생깁니다. 3주기부터는 정확한 길이의 이중가닥 산물이 생기고 이후 축적됩니다. 초기의 긴 산물도 함께 존재합니다.

02 / 10분

두 프라이머의 3′ 말단은 어디를 향할까?

  1. DNA polymerase는 primer의 3′ OH에서 연장을 시작합니다. 새 DNA는 5′→3′ 방향으로 합성됩니다.
  2. 두 primer의 3′ 말단은 서로를 향해야 합니다. 그래야 각 primer에서 시작한 DNA 합성이 두 결합 부위 사이의 표적 영역을 향해 진행됩니다.
  3. 논문과 주문서에는 F와 R 서열을 모두 5′→3′ 방향으로 씁니다.

두 primer의 3′ 말단에서 서로를 향해 합성이 진행됩니다.

상보 가닥을 주문 방향으로 읽기

앞서 본 reference strand의 오른쪽 결합 부위를 5′→3′로 읽은 8 nt 예제입니다. 방향 학습용이며 실제 PCR용 프라이머가 아닙니다.

Original / 오른쪽 결합 부위

2. 주문서에는 primer를 5′→3′로 기록합니다. 같은 상보 가닥을 반대 방향으로 읽어 보세요.

3′ T C A G G C A T 5′

↓ reverse
5′ T A C G G A C T 3′

5′3′

이처럼 reference strand를 5′→3′로 볼 때, 오른쪽 결합 부위의 역상보 서열이 그 가닥에 결합할 Reverse primer의 주문 서열이 됩니다. F/R의 화면 위아래 위치가 규칙인 것은 아닙니다.

Reverse primer의 어느 끝이 표적 내부를 향해야 하는가?

왜 Reverse primer는 역상보 서열로 주문할까?

이 그림의 위쪽 reference strand를 5′→3′로 읽으면, 그 아래에 결합하는 상보 가닥은 왼쪽 3′에서 오른쪽 5′로 놓입니다. 같은 가닥을 주문 방향인 5′→3′로 뒤집어 읽어야 합니다. 단순히 오른쪽 주형 서열을 복사하는 대신, 결합할 가닥과 3′ 말단의 합성 방향을 함께 확인하세요.

조작 방법

F 또는 R을 고르고 시작과 끝 염기를 누르세요. 마우스 드래그도 가능합니다. 터치에서는 두 번 탭해 선택합니다. 키보드는 화살표로 이동하고 Enter 또는 Space로 시작과 끝을 정합니다. Shift+화살표로 선택을 늘릴 수 있습니다. Home/End는 확대 구간의 처음/끝으로 이동합니다. Escape는 선택 중인 구간을 취소합니다.

확대 위치를 움직여 떨어진 구간까지 선택할 수 있습니다. 선택 방향은 합성 방향이 아닙니다. F는 기본적으로 오른쪽, R은 왼쪽으로 합성하며 아래에서 방향도 바꿔 볼 수 있습니다.

아직 살펴볼 관점: 길이와 GC / Tm / 3′ 말단 / 자기 상보성 / F/R 상호 상보성 / 비표적 결합. 각 관점에서 무엇을 관찰할 수 있는지 살펴보세요.

길이와 GC / 조성을 비교하기

약 18~25 nt, GC 약 40~60%는 일반적인 PCR primer에서 흔히 사용하는 출발점입니다. 범위 안에 있다고 실제 PCR 성공이나 specificity가 보장되는 것은 아닙니다.

Tm / 두 primer의 결합 조건 비교하기

간이 Tm / 교육용 근사
2×(A+T)+4×(G+C) °C로 계산합니다. 염기 개수만 사용하는 Wallace 근사이며 nearest-neighbor 계산이 아닙니다.

실제 Tm은 sequence와 함께 이온 농도, primer 농도, dNTP, 계산 모델 등의 영향을 받습니다. 이 간이값은 Na+, Mg2+, primer 농도, dNTP와 최근접 염기 효과를 반영하지 않습니다.

F와 R의 Tm이 크게 다르면 하나의 annealing 조건에서 두 primer의 결합 조건을 맞추기 어려울 수 있습니다. 이 값만으로 annealing 온도나 실제 반응 성공을 결정할 수 없습니다.

3′ 말단 / 연장이 시작되는 곳

DNA polymerase는 primer의 3′ OH에서 연장을 시작하므로 3′ 말단의 결합 특성은 특히 중요합니다. 마지막 염기와 마지막 5 nt를 관찰하세요. 5 nt보다 짧으면 전체 서열을 표시합니다.

GC 개수와 반복 염기는 검토할 특징입니다. 3′ GC clamp 하나의 유무로 좋은 primer를 판정하지 않습니다.

상보성 / primer가 서로 붙을 수 있는 구간

현재 단순 모형에서의 관찰입니다. 두 서열을 역평행으로 옮겨 가며 가장 긴 연속 상보 구간을 찾습니다. 밑줄과 |는 선택한 연속 구간을 나타냅니다.

자기 상보성은 같은 primer 두 사본의 서열을 비교합니다. 이 정렬은 실제 hairpin 형성 확률이나 자유에너지를 뜻하지 않습니다. 한 분자가 접힐 때의 고리 크기와 구조는 계산하지 않습니다.

3′ 말단 상보성이 있으면 polymerase가 연장 가능한 primer-primer 구조가 형성될 가능성을 검토할 필요가 있습니다. 실제 primer-dimer 발생 확률과 열역학적 안정성은 현재 단순 sequence model이 계산하지 않습니다.

비표적 결합 / 비교 범위를 넓히기

비교용 primer pair P1/P2/P3는 특정 개념을 비교하기 위한 교육용 고정 사례입니다. 위의 ‘내 설계’와 구분하며 자동 추천이나 정답을 뜻하지 않습니다.

P3의 결합 부위 해설 열기

B에서 target 자체가 없는 경우와 primer binding site가 사라지거나 손상되어 증폭되지 않는 경우를 구분해야 합니다. P3의 F 결합 부위는 B의 결실 안에 있으므로 이 모형에서 B 산물이 예측되지 않습니다.

문헌의 pair 준비

논문에 보고되었다는 사실과 현재 검색 조건에서 specificity가 확인되었다는 것은 같은 의미가 아닙니다. 기존 연구의 목적을 존중하면서 현재 database와 annotation 조건에서 다시 살펴봅니다.

새 후보를 찾기 위한 target 준비

가능하면 RefSeq accession을 사용하세요. Gene ID에서 시작한다면 관련 nucleotide record를 찾아 accession을 준비합니다. 이 학습지는 primer를 생성하지 않습니다.

외부 도구에 무엇을 입력하나요?
기존 pair는 Forward와 Reverse의 실제 5′→3′ 서열을 모두 입력합니다. 두 primer가 있으면 template 없이도 검색할 수 있습니다. Intended target을 알고 있다면 template/accession도 함께 제공하세요. Template와 두 primer를 모두 넣으면 새 pair 설계 대신 기존 pair의 specificity check를 수행합니다.
Pair만 넣은 검색에서는 보고된 sequence 중 무엇을 intended target으로 볼지 직접 살펴야 합니다. Template를 함께 제공하면 intended target의 정체를 해석하는 맥락을 줄 수 있습니다. 새 후보 설계는 target/template를 준비하고 원하는 product size, organism, database와 specificity checking을 확인합니다.

      

      
RNA 발현 분석이라면?
현재 NCBI의 exon/intron 설정은 RefSeq mRNA template를 요구합니다. Exon-exon junction을 가로지르는 primer 또는 genomic DNA에서 intron을 사이에 두는 pair 설정을 목적에 맞게 검토하세요. 실제 gDNA 증폭 배제나 발현 정량을 이 설정만으로 확정하지 않습니다.

      

      
NCBI 화면 구성은 변경될 수 있습니다. 버튼 위치보다 입력 정보와 검색 범위를 기록하세요.

최종 검토 안내 열기
계산의 범위, 외부 검색의 범위와 실제 실험 증거를 구별했는지 읽어 보세요. 점수를 매기는 화면이 아니라 다른 사람이 판단 과정을 이해할 수 있는 기록을 만드는 활동입니다.

    

    
선택 확장 / RNA 발현을 보려면? / 약 15분
      
RNA에서 역전사로 만든 cDNA와 gDNA는 주형의 구성이 다릅니다. 아래는 길이와 좌표를 생략한 개념도입니다.

      
      
Exon-exon junction에 걸친 프라이머는 gDNA와의 구별에 도움을 줄 수 있습니다. Intron을 사이에 둔 프라이머 쌍은 gDNA와 cDNA에서 다른 길이의 산물을 만들 수 있습니다. 어느 방식도 gDNA 증폭 가능성을 절대 0으로 보장하지 않습니다. 유사 유전자와 가공 위유전자도 검토 대상입니다.

      
RT(-) 대조군은 역전사 효소를 넣지 않은 대조입니다. 남아 있는 DNA의 영향을 살피는 데 사용합니다. qPCR에는 짧은 산물을 주로 쓰지만 실제 정량에는 증폭 효율 검증이 필요합니다. 융해 곡선의 단일 피크도 표적 산물의 정체를 보장하지 않습니다.

      
      
확장 해설 열기
검출하려는 전사체, exon 구조와 gDNA 잔존 가능성을 함께 검토하세요. 실제 정량 데이터가 없으므로 이 학습지는 Cq, 발현량이나 증폭 효율을 만들어 내지 않습니다.
